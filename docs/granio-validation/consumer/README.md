# Независимый потребитель Granio

Воспроизводит короткую проверку установки опубликованного ядра и библиотек.
Модуль содержит точную проверенную версию, не содержит `replace` и создаёт
настоящее окно с DataGrid, получает кадр и штатно закрывается.

Требуются Go 1.27.1+, компилятор C и зависимости OpenGL/оконной системы.
Запуск из этого каталога: `GOWORK=off go run -tags migrated_fynedo .`.
В PowerShell перед запуском задайте `$env:GOWORK='off'`.

Результат исходной проверки: соседний `consumer-native.log`.

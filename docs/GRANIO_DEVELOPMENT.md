# Развитие Granio: 18 октября 2026 года

Granio — самостоятельный проект на базе [Fyne](https://github.com/fyne-io/fyne).
Сохраняются история, лицензии и сведения об авторах исходников. Имя пакета,
пути Go-модулей и команды переведены на Granio. Совместимость приложений
требует согласованного переноса расширений вместе с ядром.

## Реализация

### Окна и системная тема

- Выбор Linux backend передан GLFW. Отдельное соединение с Wayland и блокирующая
  проверка server-side decorations при старте удалены.
- Автоматический выбор учитывает предпочтение сеанса и пробует доступные backend.
  Явный `FYNE_PLATFORM=x11` или `wayland` остаётся строгим выбором.
- Исправлен результат `glfw.Init`: отказ платформы возвращает ошибку, вместо
  ложного успешного завершения. Исправление внесено в обёртки 3.3, 3.4 и 3.5.
- `desktop.DisplayInfo` сообщает фактический backend через сохранённое состояние,
  без нативных вызовов из произвольного потока.
- Портал KDE предоставляет полную палитру, название схемы, стиль, описание шрифта
  и тему значков. Изменение схемы запускает чтение всей палитры; проверяются
  отправитель, владелец сервиса, формат и полнота данных.
- `FollowSystemPalette` включает использование палитры явно. Акцент приложения
  сохраняется, высокая контрастность имеет приоритет, потеря провайдера
  восстанавливает собственные цвета темы.
- Операции порталов рабочего стола используют согласованный D-Bus из собственного
  набора. Исходник `rymdport/portal v0.4.2` и его лицензия отмечены в библиотеке.

Палитра KDE применяется к семантическим ролям Granio. Стиль Qt Union и описание
шрифта передаются как метаданные; загрузка Qt-стиля или произвольного файла шрифта
не выполняется. Непредоставленные системой настройки остаются недоступными.

### Таблицы и галерея

`widget.DataGrid` использует виртуализированную `Table` и добавляет устойчивые
идентификаторы, стабильную сортировку, фильтрацию, группы и редактирование.
Значения для сравнения считываются перед сортировкой. Выбор и черновик сохраняются
при изменении представления. Ошибка проверки или записи оставляет редактор
и исходные данные; уход редактора из viewport освобождает скрытый фокус.

Галерея получила поиск на русском и английском, историю навигации, ленивое
создание страниц, копируемые фрагменты кода, диагностику темы и backend.
Пример DataGrid содержит 10 000 строк. API отмечен экспериментальным.

Метаданные папок адаптированы к типам Granio и доступны через
`storage/foldermeta`; лицензия исходного FancyFS сохранена. Файловый диалог
и терминал используют согласованные типы URI, ресурсов и изображений.

### Экосистема

[Реестр](ECOSYSTEM.md) содержит 34 выбранных репозитория Fyne и четыре библиотеки
графического и системного стека. Подготовлены собственные пути модулей,
Go 1.27.1 и русские пояснения назначения форков. Основные репозитории имеют
ссылку на исходник в описании и README.

Исправлены несовместимые тесты `widget.Box`, диагностическое форматирование UTF-16
в инструментах и жизненный цикл файлов в тесте редактора изображений.
Рецепты контейнеров переведены на Go 1.27.1. Сборка и публикация контейнеров,
облачные операции и мобильные SDK требуют отдельной проверки.

## Проверки и пределы результата

Использован Go 1.27.2; минимальная версия модулей — 1.27.1.
Длительные performance-проверки не выполнялись.

| Среда | Подтверждено |
| --- | --- |
| Windows 10.0.26300, amd64, NVIDIA RTX 4080 SUPER | Полный набор тестов ядра с race/cgocheck2; 100 циклов окна; смена масштаба текста; снимок реальных настроек ОС |
| Windows, настоящий WGL/DWM | Mica, Mica Alt, Desktop Acrylic, первый кадр, alpha и оптическое размытие; отдельные изображения и JSON |
| Linux, Xvfb/X11 | Тесты ядра, выбор backend при недоступном Wayland, материалы содержимого, жизненный цикл окна и галерея |
| Linux, Weston headless, масштаб 2, GLES2 | Нативный Wayland backend, жизненный цикл, прозрачная поверхность, fallback и запуск галереи |
| Linux, настоящий dbus-daemon | Полный набор D-Bus, watcher, смена владельца, палитра KDE и жизненный цикл провайдера |
| Windows, D-Bus | 73 выбранных протокольных теста; daemon-тесты требуют отдельного сервиса и проверены на Linux |
| JS/WASM | Сборка галереи; браузерная приёмка отдельно |
| macOS arm64 | Сборка программного варианта; нативная Cocoa-приёмка отдельно |

Linux-прогон первоначально выявил отсутствие тестового `.background.svg` в архиве:
его исключало правило swap-файлов. Правило исправлено, файл включён в исходники,
пакет повторно прошёл проверку. Исходный неуспешный лог сохраняется вместе
с результатом повторной проверки.

Свидетельства находятся в [granio-validation](granio-validation/).
В DWM-проверке средняя ошибка alpha не превысила 1 канала из 255;
стандартное отклонение шахматного фона уменьшилось с 119 до 0,449 при Acrylic.
Эти значения относятся к проверенному стенду и короткому функциональному сценарию.

Живые GNOME, KDE 5.27/X11, KDE 6.7–6.8/Wayland, Fly, нативная macOS,
Windows 22621/22631, Intel/AMD и физические смешанные DPI-мониторы остаются
в аппаратной матрице. Xvfb/Weston не подтверждают приёмку реального KWin/GNOME/Fly.

Публикация экосистемы выполняется по реестру. GitHub временно ограничивает создание
части репозиториев; подготовленные изменения сохраняются в отдельных локальных
ветках. Результат установки без workspace фиксируется после проверки опубликованного
графа модулей.

# Проверка тестов Fyne и apps

12 октября 2026 года полный desktop-набор Fyne и apps успешно проверен на Windows
с Go 1.27.1. Дополнительно проверены профили CI на Windows и f-test-bench.
Пакеты без тестовых функций в приведённые числа не включены.
Число проверок включает успешные тесты и подтесты.

| Окружение | Детектор гонок | Пакеты с тестами | Проверки |
| --- | --- | ---: | ---: |
| Windows amd64 v3, полный desktop | Да | 47 | 4855 |
| Windows amd64 v3, профиль CI | Да | 47 | 4702 |
| Windows amd64 v1, профиль CI | Нет | 47 | 4702 |
| ОСнова Linux amd64 v3, профиль CI | Да | 49 | 4722 |

## Команды

Полный desktop-набор Windows, включая GLFW-тесты с настоящим OpenGL-контекстом:

```powershell
.\scripts\build.ps1 -Task Test -Race -NativeGLFW
```

Эквивалентный полный прогон без обёртки:

```powershell
go test -race '-tags=migrated_fynedo' -count=1 ./... ./extras/apps/...
```

Обычный Windows CI-профиль upstream проверен отдельно командой
`.\scripts\build.ps1 -Task Test -Race`. Он использует `no_glfw,migrated_fynedo`.
Для полного desktop-набора нужен доступный графический desktop.

GOAMD64=v1 был проверен отдельно в процессе проверки совместимости. Рабочая
конфигурация и настоящие приложения сохраняют GOAMD64=v3.

Linux:

```bash
GOAMD64=v3 go test -p 4 -race -tags=no_glfw,ci,migrated_fynedo -count=1 ./... ./extras/apps/...
```

На f-test-bench использовались временный sysroot с заголовками GL, GLES, EGL,
X11 и Wayland, штатные runtime-библиотеки и копия публичного Go-кэша зависимостей
проекта. Подготовка выполнялась в отдельном `/tmp/fyne-tests.*` через download-only
и распаковку пакетов. Go-кэш располагался за границей поиска `./...`.

## Исправленные причины

- `test.NewApp` выбирает английский язык через `lang.SetLocale`, согласованный
  с Locale тестового устройства. Переключение на русский, возврат к системному
  выбору и сохранение выбора при добавлении переводов проверяются отдельно.
- Пиксели RGBA и NRGBA сравниваются в одинаковом представлении. Прозрачные цвета
  не увеличивают минимальную разницу alpha до ложной разницы 255 в RGB.
  Геометрия изображения сравнивается до пикселей. Для amd64 применяется тот же
  ограниченный численный допуск, который уже использовался для darwin/arm64:
  максимум 30 на канал и средняя разница строго ниже 0,5 на байт.
  Проверки сохраняют отбраковку видимых и массовых изменений.
- Watcher наблюдает каталог и фильтрует имя нужного файла. Удаление и создание
  файла вызывают callback; удалять watch на отсутствующий файл не требуется.
  Соседние файлы не вызывают лишних перезагрузок. Проверка watcher повторена 10 раз.
- GLFW-тесты на Windows ожидают обработку resize и при необходимости повторяют
  запрос размера, как уже делали проверки других desktop-платформ. Точное
  сравнение размеров остаётся обязательным; численный допуск для геометрии не вводился.
- В apps исправлены map-literal, платформенная фильтрация Linux-приложения,
  сравнение даты UTC и обязательная проверка наличия screenshot перед индексированием.

Исходные эталонные изображения не обновлялись, новых пропусков тестов не добавлено.
Каждый профиль сохраняет 3 исходных upstream skip. Статусы отдельных пакетов
и время прогонов сохранены в [test-results.json](test-results.json).
Полный Windows-профиль включает оконный драйвер GLFW; Linux и Windows CI-профили
используют `no_glfw`. Настоящие
`fyne_settings.exe` и `apps.exe` дополнительно успешно пересобраны на Windows
с GLFW/OpenGL. Проверки реальных видеодрайверов и мобильных IME остаются
самостоятельными сценариями из [обзора issues](ISSUES_AUDIT.md).

## Воспроизводимость apps

Изменения подмодуля находятся в `patches/apps-tests.patch`. Применение и обратная
проверка патча выполнены на чистой локальной копии upstream commit
`c977ab9a872c439a5e84c0edaaf533f81cf19e70`. Повторный запуск build.ps1 распознаёт
уже применённые изменения; конфликтующие пользовательские правки не перезаписываются.

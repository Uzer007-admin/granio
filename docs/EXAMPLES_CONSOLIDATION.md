# Объединение примеров Granio

18 октября 2026 года.

Демонстрации, учебные проекты, небольшие приложения и рецепты упаковки собраны
в [granio-examples](https://github.com/Uzer007-admin/granio-examples).
Основной исходник — [fyne-io/examples](https://github.com/fyne-io/examples).
Происхождение остальных наборов и их коммиты указаны в
[SOURCES.json](https://github.com/Uzer007-admin/granio-examples/blob/dev/granio/SOURCES.json).

## Результат

- Один активный Go-модуль, Go 1.27.1+, общие зависимости и корневые workflow.
- Каталоги `calculator`, `life`, `solitaire`, `pixeledit`, `demo`, `7guis`,
  `tutorials`, `workshops`, `packaging/flatpak` и `packaging/web`.
- Исправлены внутренние импорты, пути ресурсов и упаковки. Независимые занятия
  `bind`, `custom` и `extend` разделены по каталогам с отдельными `main`.
- Истории девяти наборов включены в Git. Имеющиеся LICENSE и AUTHORS сохранены
  рядом с исходниками и сверены побайтово. Исторические модули и workflow
  сохранены как материалы источников; активные зависимости задаёт корневой модуль.
- Веб-демонстрация собирается из выбранного коммита общего репозитория.
  Готовый WebAssembly не хранится в Git. Рядом с результатом записывается
  `SOURCE.json` с коммитом и версией упаковщика.

Пять отдельных репозиториев удалены по указанию владельца после проверки переноса:
`granio-calculator`, `granio-demo`, `granio-7guis`, `granio-tutorials`
и `granio-flatpak-demo`. GitHub подтвердил удаление; API возвращает HTTP 404.
Исходные рабочие коммиты доступны в опубликованном общем репозитории.
Собственных обращений и выпусков в удалённых форках не было.
Подтверждения — [deleted-repositories.json](examples-consolidation/deleted-repositories.json).

Создание отдельных репозиториев для life, solitaire, pixeledit, workshops
и web-demo исключено из плана. Активный набор сокращён с 38 до 28 репозиториев;
25 опубликованы. Studio, catalog и addons остаются подготовленными локально.
Библиотека терминала и инструменты сохраняют самостоятельные репозитории.

## Проверка

Проверяемый коммит кода: `c44e896c7d4a6a14a806689dc9494f9ccfee3a71`.
Использован Go 1.27.2; минимальная версия в модуле — 1.27.1.

| Проверка | Результат |
| --- | --- |
| Windows: `go test -p 1 -race -tags migrated_fynedo,ci -timeout 3m ./...` | Пройдены 37 пакетов, из них 8 с тестами |
| Windows: `go build -p 1 -tags migrated_fynedo ./...` | Нативная сборка всего набора прошла |
| Linux, f-test-bench: race-тесты общего модуля с `-mod=vendor` | Пройдены те же 37 пакетов, из них 8 с тестами |
| Linux: нативная сборка всех примеров и `go vet` | Пройдены без сетевой загрузки зависимостей |
| Web: `packaging/web/update.sh HEAD` в Windows/Git Bash | Сформированы WASM, HTML, ресурсы и сведения об источнике |
| Linux: `sh -n packaging/web/update.sh` | Синтаксис POSIX shell проверен |
| Flatpak: общий vendor и нативная Linux-сборка из него | Проверены; пути рецепта обновлены |
| Истории Git, активный модуль и лицензии | Девять историй доступны, активный модуль один, лицензионные файлы совпадают |

Сводка команд и результатов: [checks.json](examples-consolidation/checks.json).
Логи сохранены в [examples-consolidation](examples-consolidation/).
Сведения о файлах веб-сборки, размерах и SHA-256 —
[proof.json](examples-consolidation/proof.json).

Тесты с `ci` используют программную отрисовку. Эти проверки не заменяют
визуальную приёмку каждого примера на Windows, Linux, macOS и мобильных
устройствах. Нативная сборка подтверждает компиляцию, но не поведение окон.
Запуск сайта в браузере и установка Flatpak на этом этапе не проверялись.
Длительные измерения производительности не выполнялись.

## Сопровождение

Реестр [repositories.json](../ecosystem/repositories.json) хранит отдельно
активные репозитории и происхождение объединённых примеров. Издатель
`ecosystem/publish.py` не создаёт удалённые или отменённые репозитории примеров;
при явном `--only granio-calculator` выводит новое расположение и завершает работу.
Локальный полный workspace подключает только общий модуль примеров.

Снимок `granio-validation/repositories.json` относится к предыдущему этапу
публикации. Текущее состояние описывают реестр и этот отчёт.

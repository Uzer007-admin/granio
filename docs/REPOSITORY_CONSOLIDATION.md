# Объединение репозиториев Granio

18 октября 2026 года.

Рабочий набор сокращён с **28 до 11 репозиториев**. Все 11 опубликованы.
На этом этапе объединены 17 компонентов: 14 ранее опубликованных репозиториев
удалены, создание отдельных Studio, catalog и addons отменено.
С учётом предыдущего объединения примеров исходники 38 компонентов
сопровождаются в 11 репозиториях.

## Новое размещение

| Цель | Перенесённые компоненты |
| --- | --- |
| [granio](https://github.com/Uzer007-admin/granio) | `deps/gl-js`, `deps/glfw-js`, `deps/systray`, `deps/image`, `deps/oksvg` |
| [granio-x](https://github.com/Uzer007-admin/granio-x) | Терминальный виджет, описание и редактирование UI, облачные провайдеры, локаль |
| [granio-tools](https://github.com/Uzer007-admin/granio-tools) | Проверка окружения, Studio, кросс-сборщик, рецепты образов и мобильный мост |
| [granio-xgb](https://github.com/Uzer007-admin/granio-xgb) | Протокол X11 и `xgbutil` |
| [granio-docs](https://github.com/Uzer007-admin/granio-docs) | Документация, `sites/catalog`, `sites/addons` |
| [granio-examples](https://github.com/Uzer007-admin/granio-examples) | Приложение терминала, демонстрации расширений, облака и локали |

Самостоятельными остаются ядро, расширения, инструменты, примеры, приложения,
документация, X11 и четыре независимые библиотеки `gl`, `glfw`, `glow`, `dbus`.

Библиотека терминала импортируется по
`github.com/Uzer007-admin/granio-x/terminal`. Приложение запускается из
репозитория примеров командой `go run ./terminal`. Studio использует этот же
виджет; дублирующая реализация не создаётся.

Один репозиторий может содержать несколько Go-модулей. У ядра пять встроенных
модулей в `deps`; у инструментов отдельно выделены `cross` и `mobile-bridge`.
Studio и проверка окружения входят в основной модуль инструментов.
Это не добавляет Kubernetes/AWS в граф обычного упаковщика.
Полный локальный workspace содержит 22 модуля.

## История, лицензии и ссылки

Все 17 исходных коммитов доступны в целевых репозиториях GitHub.
Файлы `SOURCES.json` задают исходник, коммит и новое расположение;
прежние адреса служат сведениями о происхождении.
17 имеющихся файлов LICENSE/AUTHORS сверены с исходными Git-объектами
и сохранены с исходными байтами, включая окончания строк.
Темы двух каталогов зарегистрированы как подмодули по новым путям.

Удаление 14 репозиториев подтверждено GitHub и последующими ответами API HTTP 404.
Собственных обращений и выпусков в них не было. Подтверждения:
[deleted-repositories.json](repository-consolidation/deleted-repositories.json).
Все оставшиеся репозитории перечислены в
[remaining-repositories.json](repository-consolidation/remaining-repositories.json).

Описания GitHub и README обновлены на русском языке; основной и дополнительные
исходники указаны явно. Издатель поддерживает `--metadata` и исключает
объединённые компоненты из создания и публикации.

## Исправления, найденные при проверке

- Терминал: синхронизировано открытие канала ввода и чтение кода завершения.
  ConPTY закрывается один раз, дескриптор процесса освобождается;
  ошибка ожидания дочернего процесса не завершает весь GUI через `log.Fatal`.
  Проверены завершения PowerShell с кодами 0, 1 и 2147483647; внутреннее
  атомарное состояние не переполняется на верхней границе Int32. Тесты ограничены по времени
  и отправляют штатный для соответствующей оболочки символ Enter.
- Облачные настройки: остановлены наблюдатель и отложенная запись при Disconnect,
  запись файлов сериализована, ошибки закрытия файла возвращаются вызывающему коду.
  Отложенные изменения объединяются одним таймером. Список слушателей возвращается
  независимым снимком; неполный JSON не подменяет живые настройки.
  JSON `null` загружается как пустой словарь, сохраняющий возможность записи.
  Тесты используют собственные временные файлы.
- Снимки JSON UI согласованы с полями `Strikethrough` и `TextRole` текущего ядра.
- Потребители, команды установки, метаданные приложений, CI и рецепты упаковки
  переведены на новые адреса модулей. Упаковщик и Studio устанавливаются с GitHub
  без локального workspace и `replace`.
  Проверка загрузки метаданных согласована с новым адресом репозитория
  и каталогом `cmd/granio/internal/metadata/testdata`.

## Проверки

Использован Go 1.27.2; минимум во всех затронутых Go-модулях — 1.27.1.
Все функциональные проверки выполнены с опубликованным графом зависимостей
или автономной копией `vendor` этого же графа.

## Границы результата

Windows-набор использует `migrated_fynedo,ci,no_glfw` и исключает ровно пакет
`internal/driver/mobile`: его тестовый инициализатор не поддерживает Windows+ci.
Этот пакет проверен в полном Linux-наборе. Пробный общий Windows-прогон выявил
эту несовместимость тегов и нестабильную под нагрузкой проверку частоты кадров;
исходные результаты сохранены. Исходники этих тестов в рамках этапа не менялись.

Нативная сборка подтверждает компиляцию; она не заменяет визуальную приёмку
каждого приложения. Xvfb не подтверждает работу эффектов KDE, GNOME, Fly
или Wayland-композитора. macOS, Android/iOS и мобильные SDK на оборудовании
не перепроверялись. Перенос мобильного моста проверяет доступные переносимые пакеты.

Рецепты контейнеров используют пространство `ghcr.io/uzer007-admin/granio-cross`
и закреплённые версии инструментов. Сборка и публикация готовых образов,
развёртывание сайтов, полноценная Hugo-сборка и браузерная приёмка WASM
в этот этап не включены. Длительные performance-проверки не выполнялись.

## Обновление приложений

Пути импортов изменились. Замените старые префиксы по
[таблице миграции](MIGRATION_GRANIO.md#объединение-репозиториев-granio)
и используйте версии из [modules.json](../ecosystem/modules.json).
Старые версии, зависящие от удалённых репозиториев, не являются целями
текущего сопровождения; автоматического перенаправления Go-импортов нет.

# Короткая проба Win32/WGL

Инструмент Granio для сравнения обычного окна GLFW без графического API и
окна с WGL/OpenGL. Исходник GLFW — [go-gl/glfw](https://github.com/go-gl/glfw),
обёрток GL — [go-gl/gl](https://github.com/go-gl/gl).

Нужны Windows, Go 1.27.1+ и C-компилятор. Из этого каталога:

```powershell
$env:GOWORK='off'
go run . noapi
go run . wgl
```

`noapi` создаёт и сразу удаляет скрытое окно `GLFW_NO_API`.
`wgl` ненадолго показывает зелёное тестовое окно 320×240, проверяет исходный
swap interval и делает по 12 представлений при исходном интервале, 0 и 1.
Затем собственное окно и GLFW освобождаются. Другие окна не управляются;
настройки драйвера не меняются. Значения интервала относятся только к
тестовому окну. Адреса-сигналы отказа WGL не вызываются как функции.

В stdout идут JSON-строки с временами этапов. Длительность `SwapBuffers`
измеряется через `QueryPerformanceCounter`; это время возврата API, а не
момент физического отображения. Создание WGL включает инициализацию ICD и
контекста внутри GLFW. Один запуск не даёт p95/p99 и не устанавливает причину
подвисания других процессов. Для этого нужна системная GPU-трасса:
[описание проверки](../../docs/WINDOWS_DESKTOP_STALL_DIAGNOSIS.md).
